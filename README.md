# Site pessoal - Thiago Mazzaroli

- **Aluno:** Thiago Mazzaroli
- **Disciplina:** PW14SW — UTFPR · Projeto incremental 1: Site pessoal
- **Site publicado:** https://thiagomazzaroli.github.io/Site_Pessoal_Web1/

## Objetivo

Construir, em três etapas incrementais, um site pessoal que apresenta minha formação, minha experiência como desenvolvedor full stack na LeadFinder, projetos, habilidades e uma área de contato.

## Etapas

| Etapa | Onde está | O que foi feito |
| --- | --- | --- |
| 1. HTML puro | [`etapas/etapa-1-html/`](etapas/etapa-1-html/) | Estrutura básica (`<!DOCTYPE html>`, `html`, `head`, `body`) e elementos semânticos: títulos, parágrafos, listas, links, imagens, navegação por âncoras e área de contato. Sem CSS e sem JavaScript. |
| 2. CSS | [`etapas/etapa-2-css/`](etapas/etapa-2-css/) | O mesmo HTML com um arquivo CSS externo: cores, tipografia, espaçamentos, bordas, tamanhos, links, cartões e estados `:hover`/`:focus`. |
| 3. Mobile First | raiz: [`index.html`](index.html) e [`css/style.css`](css/style.css) | CSS refeito a partir da tela pequena: `viewport`, unidades relativas (`rem`, `%`, `clamp()`), imagens fluidas, Flexbox, Grid e media queries em 768px e 1200px. |
