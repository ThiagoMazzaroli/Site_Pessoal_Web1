Sobre mim

Sou desenvolvedor full stack na LeadFinder e estudante da UTFPR. No dia a dia trabalho em todas as camadas do produto: modelo dados no PostgreSQL, escrevo serviços em Java, integro sistemas por meio de filas e webhooks e construo interfaces em Angular com TypeScript.

Gosto especialmente de problemas em que a confiabilidade importa: eventos que chegam fora de ordem, mensagens que não podem ser processadas duas vezes e grandes volumes que precisam rodar em lote sem afetar o restante do sistema. Também tenho levado inteligência artificial para dentro do produto, com agentes que consultam uma base de conhecimento e executam ações reais.

  • 3 canais integrados: Instagram, Facebook e WhatsApp
  • 300+ campos disponíveis no gerador de relatórios
  • De ponta a ponta do banco de dados ao frontend

Interesses

Projetos e principais entregas

Algumas das funcionalidades que desenvolvi na LeadFinder e o próprio projeto deste site.

Integração com Instagram, Facebook e WhatsApp

Arquitetura orientada a eventos com webhooks e filas AWS SQS. O processamento é idempotente e trata eventos que chegam fora de ordem; a autenticação usa OAuth e as mídias recebidas passam por um pipeline até o Amazon S3, com retentativas automáticas.

  • Webhooks
  • AWS SQS
  • OAuth
  • Amazon S3

Automação de marketing

Máquina de estados que reage a aberturas, cliques e respostas de campanhas de e-mail e WhatsApp, inclusive à falta de interação dentro de janelas de tempo. Grandes volumes são processados em lotes agendados.

  • Java
  • Máquina de estados
  • Jobs agendados

Campos personalizáveis

Modelo de dados dinâmico e tipado que permite a cada cliente criar os próprios campos sem alterar o banco. Os campos aparecem automaticamente em documentos, relatórios e na API pública.

  • PostgreSQL
  • Modelagem de dados
  • API REST

Gerador de relatórios self-service

O próprio usuário monta o relatório escolhendo entre mais de 300 campos, e as planilhas são geradas dinamicamente no backend.

  • Java
  • Angular
  • Planilhas

IA aplicada ao atendimento

Chat de teste multimodal (texto, áudio e imagem) com comunicação assíncrona com o provedor de IA, base de conhecimento consultada pelos agentes via API e ações executadas pela própria IA, como o agendamento de reuniões.

  • IA
  • Multimodal
  • Assíncrono

Automação no fluxo de mensagens

No fluxo crítico de mensagens, novas conversas viram registros de venda em tempo real, com deduplicação de clientes vindos de integrações externas.

  • Tempo real
  • Deduplicação
  • Integrações

Escalabilidade e segurança

Invalidação de cache sincronizada entre servidores via filas, reformulação da gestão de sessão no frontend e controle de acesso hierárquico nas consultas do backend.

  • Cache distribuído
  • Sessão
  • Controle de acesso
